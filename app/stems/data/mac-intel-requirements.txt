# The separation runtime on Intel Macs, installed with `pip install --no-deps`.
#
# PyTorch published its last Intel macOS build with 2.2.2, and audio-separator
# has declared torch>=2.3 and numpy>=2 since 0.24.3, so pip cannot resolve the
# current separator there on its own. This set overrides only those two
# requirements; every other package satisfies what it declares. The versions
# are the last with Intel macOS wheels (numba 0.62, llvmlite 0.45, onnxruntime
# 1.23, ml-dtypes 0.5, scipy 1.15). Python 3.10 installs from wheels alone;
# 3.11 and 3.12 build diffq from source and need the Command Line Tools.
#
# Regenerate after changing SEPARATOR_VERSION or SUPPORT_PACKAGES:
#
#   printf 'audio-separator[cpu]==0.44.5\nlibrosa==0.11.0\nimageio-ffmpeg==0.6.0\n' |
#     uv pip compile - --python-version 3.10 --python-platform x86_64-apple-darwin \
#       --override <(printf 'torch==2.2.2\nnumpy<2\n') \
#       -c <(printf 'numba<0.63\nllvmlite<0.46\nonnxruntime==1.23.2\nml-dtypes<0.6\nscipy<1.17\n') \
#       --no-header --no-annotate
#

# audio-separator's torch and numpy requirements.
